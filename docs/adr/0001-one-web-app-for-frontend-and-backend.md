# หน้าบ้านและหลังบ้านอยู่ในแอปเว็บตัวเดียว

Blanksong มีคนทำคนเดียวกับ agent หลายตัว ไม่มีงบ และต้องเดินเส้นทางหลักได้เร็วที่สุด เราจึงเขียนด้วย TypeScript ทั้งระบบ และให้หน้าเว็บกับส่วนประมวลผลฝั่งเซิร์ฟเวอร์อยู่ในแอป Next.js ตัวเดียว ไม่แยกเป็นสองบริการ เพราะการแยกเพิ่มงานเรื่องการเข้าสู่ระบบข้ามบริการ การรันสองตัว และสัญญาระหว่างสองฝั่ง โดยที่ระบบสาธิตผู้ใช้ 20 คนยังไม่ได้ประโยชน์จากการแยก

กฎของธุรกิจ (สต็อก คำสั่งซื้อ การจ่ายเงิน การจัดส่ง) อยู่ในโมดูลฝั่งเซิร์ฟเวอร์ที่ไม่รู้จักหน้าเว็บ หน้าเว็บเรียกผ่านโมดูลเหล่านี้เท่านั้น ถ้าวันหนึ่งต้องแยกหลังบ้านออกเป็นบริการของตัวเอง ให้ย้ายโมดูลชุดนี้ออกไป

## Considered Options

- แยกแอปหน้าบ้านกับบริการหลังบ้าน: ตรงกับภาพ "FE กับ BE" มากกว่า แต่เพิ่มงานต่อเชื่อมที่รุ่นนี้ยังไม่ต้องใช้
