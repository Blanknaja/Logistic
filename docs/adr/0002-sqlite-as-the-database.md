# ใช้ SQLite เป็นฐานข้อมูล

Blanksong รุ่นนี้เป็นระบบสาธิตที่รันบนเครื่องเดียว ไม่มีงบ และรับผู้ใช้พร้อมกัน 20 คน เราจึงเก็บข้อมูลใน SQLite ไฟล์เดียว เพราะไม่ต้องเปิดบริการฐานข้อมูลแยก ใครโคลน repo แล้วรันได้ทันที ตอนตัดสินใจ (2026-11-24) เครื่องที่ใช้พัฒนาไม่มี Docker และ PostgreSQL เปิดอยู่

การจองสต็อกชิ้นสุดท้ายพึ่งการที่ SQLite เขียนทีละรายการ ถ้าย้ายไปฐานข้อมูลอื่น ต้องทดสอบกรณีสองคนแย่งชิ้นสุดท้ายใหม่

## Considered Options

- PostgreSQL: เหมาะกับการใช้งานจริงมากกว่า แต่ต้องมีบริการฐานข้อมูลเปิดอยู่ทั้งตอนพัฒนาและตอนทดสอบ ให้ย้ายไปเมื่อมีผู้ใช้จริงหรือรันมากกว่าหนึ่งเครื่อง
