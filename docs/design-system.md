# หน้าตาของแอป

หน้าตาทั้งแอปมาจากต้นแบบ B "เรื่องเล่า": พื้นกระดาษ ตัวหนังสือ Noto Serif Thai มุมเหลี่ยม สีเน้นเขียวเข้มสีเดียว แบ่งส่วนด้วยเส้น ไม่ใช้เงาหรือกล่องซ้อนกล่อง

- ค่าทุกตัวอยู่ใน `:root` ของ `src/app/globals.css` ใช้ผ่าน `var()` เท่านั้น ห้ามพิมพ์สี ขนาดตัวอักษร หรือระยะเป็นตัวเลขเอง
- ฟอนต์โหลดครั้งเดียวใน `src/app/layout.tsx` ด้วย `next/font` ห้ามโหลดฟอนต์อื่นเพิ่ม
- หน้าที่ทำเสร็จแล้วให้ดูเป็นแบบอย่าง: หน้าสินค้า `src/app/products/[productId]/page.tsx` กับส่วน "หน้ารายละเอียดสินค้า" ใน `src/features/browse/components/browse.module.css` ภาพอยู่ที่ `docs/screenshots/design/`

## กฎ

- สีเน้นใช้กับปุ่มหลักปุ่มเดียวของหน้า คือ `class="button"` ปุ่มอื่นใช้ `button button-secondary` ห้ามใช้สีเน้นกับลิงก์ ราคา หัวข้อ หรือ chip ที่เลือกอยู่
- ของที่เลือกอยู่ (chip รูปย่อ ปุ่มที่กดค้าง) ใช้เส้นขอบเข้ม `box-shadow: inset 0 0 0 2px var(--color-text)` กับตัวหนา
- ข้อความสำเร็จใช้สีตัวหนังสือปกติ ไม่มีสีเขียว
- มุมใช้ `--radius` อย่างเดียว รูปและกรอบรูปไม่มีมุม ห้าม `999px`
- ไม่มีเงา ไม่มี gradient แยกส่วนด้วยเส้น: `--color-text` เปิดส่วนสำคัญ (แถบซื้อ) `--color-border` คั่นส่วนอื่นและแถวในรายการ
- ตัวหนังสือมีสองน้ำหนักคือ 400 กับ 700 ค่า 600 จะแสดงเป็น 700
- ระยะในกลุ่มใช้ `--space-1` ถึง `--space-4` ระหว่างส่วนของหน้าใช้ `--space-6` หรือ `--space-7`
- เนื้อหาอยู่ใน `.container` ที่ layout ใส่ให้แล้ว ของที่ต้องชนขอบจอใช้ `margin-inline: calc(-1 * var(--gutter))` ลิงก์ที่มี padding ต้องดึงกลับให้ตัวหนังสือตรงขอบเนื้อหา แบบ `.seller-menu`
- วงโฟกัสตั้งไว้ที่ `:focus-visible` ทั้งแอปแล้ว ห้าม `outline: none` ถ้าซ่อน input ไว้ เช่น radio ใน chip ให้ใส่วงที่ตัวห่อด้วย `:has(input:focus-visible)` แบบ `.choice`
- hover เปลี่ยนสีหรือเส้นขอบด้วย `--duration` `--ease` และห่อด้วย `@media (hover: hover)` ตอนกดย่อ `scale(0.98)` ไม่มีของที่ขยับตามการเลื่อนหน้า
- breakpoint มีสามค่า เขียนจอเล็กก่อนแล้วใช้ `min-width`
  - 600: gutter 32 รูปย่อใหญ่ขึ้น
  - 900: gutter 48 หัวเรื่องและราคาใหญ่ขึ้น ส่วนของหน้าแบ่งคอลัมน์ 4:8 (`minmax(0, 4fr) minmax(0, 8fr)`)
  - 1200: เนื้อหาหยุดกว้างที่ `--content-width`
- บนจอ 390x844 ปุ่มหลักต้องกดได้ในจอแรก ถ้าอยู่ต่ำกว่านั้น ให้ติดขอบล่างจอ แบบ `.buyBar` ของหน้าสินค้า (ต่ำกว่า 900 จุด) แล้วเว้นท้ายหน้าไว้ไม่ให้แถบบังเนื้อหา
- จอกว้าง 360 จุดต้องไม่ล้นจนเลื่อนซ้ายขวาได้ e2e ตรวจทุกหน้าในเส้นทางหลัก

## class กลางใน globals.css

`.container` `.page` `.button` `.button-secondary` `.input` (ใช้กับ input select textarea) `.field` `.field-error` `.card` `.chips` `.chip` `.state` `.nav-list` `.nav-link` `.seller-menu`

ใน `*.module.css` ชื่อ class กลางต้องห่อด้วย `:global()` เช่น `.actions > :global(.button)` ถ้าไม่ห่อ CSS modules จะเปลี่ยนชื่อ class และกฎนั้นไม่มีผล ตัวอย่างที่ยังพังอยู่คือ `.price .input` ใน `browse.module.css` ช่องราคาของหน้าแรกจึงกว้างเต็มแถว

## รายการตรวจเมื่อปรับหน้าตา module ของ feature หนึ่ง

1. เปิด test ของ feature นั้นก่อน หลายตัวอ่านไฟล์ CSS หรือ markup ตรงๆ เช่น `class="button"` และ `min-width: var(--tap)`
2. สีที่พิมพ์เอง (`#...` `rgb(...)`) เปลี่ยนเป็น token ถ้าไม่มีตัวที่ตรง ให้เพิ่มใน `globals.css` กับตารางข้างบนพร้อมกัน ห้ามมีสองชื่อที่ค่าเดียวกันและใช้กับเรื่องเดียวกัน
3. ระยะ (`4px` `8px` `12px`) เปลี่ยนเป็น `--space-*` ขนาดตัวอักษร (`0.9rem` `1.6rem`) เปลี่ยนเป็น `--text-*`
4. ไล่ `--color-primary` ทุกที่ เหลือไว้เฉพาะปุ่มหลักของหน้า
5. `border-radius` ค่าอื่นเปลี่ยนเป็น `var(--radius)` หรือลบ `outline` ที่เขียนเองเปลี่ยนเป็น `var(--focus-ring)` `var(--focus-offset)` `font-weight: 600` เปลี่ยนเป็น `700`
6. ห้ามเปลี่ยนข้อความ ชื่อช่องในฟอร์ม ที่อยู่หน้าเว็บ หรือพฤติกรรม ถ้าคิดว่าควรเปลี่ยน ให้เขียนไว้ในสรุปงาน
7. ถ่ายภาพที่จอกว้าง 1440 และ 390 แล้วเปิดดูเอง เช่น `pnpm exec playwright screenshot --channel chrome --viewport-size 390,844 <ที่อยู่> <ไฟล์>` ภาพแบบ `--full-page` วาดแถบที่ติดขอบจอไว้กลางภาพ ถ้าหน้ามีแถบแบบนี้ ให้ตั้งความสูงจอเท่าความสูงหน้าแทน
8. `pnpm check` และ `pnpm e2e` ผ่าน
