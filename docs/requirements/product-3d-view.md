## 1. เป้าหมายและตัวเลขความสำเร็จ

- เป้าหมาย: ผู้ซื้อหมุนดูสินค้าได้รอบตัว และลองวางสินค้าขนาดจริงในห้องของตัวเองผ่านกล้องมือถือ ก่อนตัดสินใจซื้อ
- วัดความสำเร็จจาก: เจ้าของโปรเจคเปิดหน้าสินค้าตัวอย่างที่มีไฟล์ 3 มิติบนแล็ปท็อป แล้วหมุนดูสินค้าได้ภายใน 10 วินาทีหลังกด "ดูแบบ 3 มิติ" และในบทบาทผู้ขาย เพิ่มไฟล์ 3 มิติให้สินค้าหนึ่งชิ้นได้ภายใน 1 นาที โดยไม่มีใครช่วย

## 2. ขอบเขต

### ทำ

- ผู้ขายเพิ่ม เปลี่ยน และเอาไฟล์ 3 มิติออกจากสินค้าของร้านตัวเอง สินค้าละไม่เกินหนึ่งไฟล์ ไม่บังคับ
- หน้าสินค้าแสดงทางเข้า "ดูแบบ 3 มิติ" ในแกลเลอรีของสินค้าที่มีไฟล์ 3 มิติ
- ผู้ซื้อหมุนและซูมสินค้าในหน้าสินค้า
- บนมือถือที่วางของในห้องผ่านกล้องได้ ผู้ซื้อกด "ดูในห้องของคุณ" เพื่อวางสินค้าขนาดจริง
- ข้อมูลตัวอย่างมีสินค้าที่มีไฟล์ 3 มิติ

### ไม่ทำ

- ไฟล์ 3 มิติแยกตามแบบย่อย เพราะรุ่นแรกหนึ่งไฟล์ต่อสินค้าพอให้เห็นประสบการณ์จริง
- หน้าต่าง 3 มิติแยกที่มีราคาและปุ่มใส่ตะกร้าอยู่ข้างใน เพราะหน้าสินค้ามีสองอย่างนี้อยู่แล้ว
- QR code บนจอใหญ่ที่พามือถือไปเปิดกล้องทันที เพราะยังไม่มีที่อยู่เว็บสาธารณะให้มือถือเปิด
- ตรวจว่าของในไฟล์มีขนาดจริงถูกต้อง เพราะระบบตรวจไม่ได้ จึงแค่บอกผู้ขายในฟอร์ม
- สร้างไฟล์ 3 มิติจากรูปถ่ายให้ผู้ขาย เพราะผู้ขายต้องเตรียมไฟล์มาเอง
- วิดีโอสินค้า (ดู PRD)

### ข้อจำกัด

- ไม่มีงบ จึงใช้เฉพาะเครื่องมือที่ไม่มีค่าใช้จ่าย
- การวางของในห้องผ่านกล้องต้องใช้มือถือจริง และมือถือต้องเปิดแอปผ่านการเชื่อมต่อที่ปลอดภัย แล็ปท็อปลองได้แค่การหมุนดู
- ไฟล์ 3 มิติในข้อมูลตัวอย่างต้องมีสัญญาอนุญาตที่ใช้ได้โดยไม่ต้องให้เครดิต เพราะ repo เป็น public

## 3. ผู้ใช้และสิทธิ์

| บทบาท | ทำได้ | ทำไม่ได้ |
|---|---|---|
| ผู้ขาย | เพิ่ม เปลี่ยน และเอาไฟล์ 3 มิติออกจากสินค้าของร้านตัวเอง | แตะไฟล์ 3 มิติของสินค้าร้านอื่น (ดู PRD-012) |
| ผู้ซื้อ และคนที่ยังไม่เข้าสู่ระบบ | ดูแบบ 3 มิติ และดูในห้องของตัวเอง สำหรับสินค้าที่เปิดหน้าสินค้าได้ (ดู BRW-007) | ดูไฟล์ 3 มิติของสินค้าที่เป็น `ร่าง` `ซ่อน` หรือ `ลบแล้ว` ผ่านหน้าสินค้า |
| ผู้ดูแลแพลตฟอร์ม | ดูได้เหมือนผู้ซื้อ | เพิ่มหรือเอาไฟล์ 3 มิติออกแทนร้าน |

## 4. Requirements

### P3D-001 ผู้ขายเพิ่มไฟล์ 3 มิติ

- ลำดับความสำคัญ: ต้องมี
- WHEN ผู้ขายเลือกไฟล์ในช่อง "ไฟล์ 3 มิติ" ของหน้าฟอร์มสินค้า THE SYSTEM SHALL รับเฉพาะไฟล์ชนิด GLB ที่ขนาดไม่เกิน 10 MB โดยตรวจชนิดจากเนื้อไฟล์ ไม่ใช่จากนามสกุล แสดงชื่อไฟล์และขนาดของไฟล์ที่รับแล้ว และผูกไฟล์นั้นกับสินค้าเมื่อผู้ขายบันทึกสินค้าสำเร็จ

กรณีปกติ

- Given สมชายเป็นเจ้าของร้าน "ร้านสมชาย" กำลังแก้สินค้า "เก้าอี้ผ้ากำมะหยี่" ที่ยังไม่มีไฟล์ 3 มิติ เวลา 10:00 ใต้ช่องมีข้อความ "ไฟล์ .glb ไม่เกิน 10 MB ของในไฟล์ต้องมีขนาดจริง หน่วยเป็นเมตร"
- When สมชายเลือกไฟล์ `chair.glb` ขนาด 3.9 MB แล้วกดบันทึก เวลา 10:01
- Then ระหว่างส่งไฟล์เขาเห็นแถบความคืบหน้า เมื่อเสร็จเห็น "chair.glb 3.9 MB" พร้อมปุ่ม "เอาออก" หลังบันทึกเห็นข้อความยืนยันตาม PRD-007 และหน้าสินค้าของ "เก้าอี้ผ้ากำมะหยี่" มีทางเข้า "ดูแบบ 3 มิติ"

กรณีผิดพลาด (ไฟล์ไม่ผ่านเงื่อนไข)

- Given สมชายอยู่ที่หน้าฟอร์มของสินค้าเดิม เวลา 10:05
- When สมชายเลือกไฟล์รูป JPG ที่ถูกเปลี่ยนนามสกุลเป็น `photo.glb` แล้วเลือกไฟล์ GLB `big.glb` ขนาด 12 MB
- Then ไฟล์แรกเห็นข้อความ "photo.glb: ไฟล์ต้องเป็นชนิด GLB" ไฟล์ที่สองเห็นข้อความ "big.glb: ไฟล์ 3 มิติต้องมีขนาดไม่เกิน 10 MB" ไม่มีไฟล์ไหนถูกรับ และข้อมูลอื่นในฟอร์มยังอยู่ครบ

กรณีผิดพลาด (ไฟล์มาช้า)

- Given สมชายเลือกไฟล์ GLB ขนาด 9 MB เวลา 10:07 ขณะที่สัญญาณอินเทอร์เน็ตช้า
- When ผ่านไป 60 วินาทีแล้วไฟล์ยังส่งไม่เสร็จ
- Then ช่องนั้นแสดงข้อความ "ส่งไฟล์ไม่สำเร็จ" พร้อมปุ่ม "ลองใหม่" และปุ่ม "เอาออก" ข้อมูลอื่นในฟอร์มยังอยู่ครบ และปุ่มบันทึกกดไม่ได้จนกว่าไฟล์ที่ค้างจะส่งสำเร็จหรือถูกเอาออก

### P3D-002 เปลี่ยนและเอาไฟล์ 3 มิติออก

- ลำดับความสำคัญ: ต้องมี
- WHEN ผู้ขายกด "เอาออก" ที่ไฟล์ 3 มิติ หรือเลือกไฟล์ใหม่แทนไฟล์เดิม แล้วบันทึกสินค้าสำเร็จ THE SYSTEM SHALL ใช้ผลนั้นกับหน้าสินค้าภายใน 1 นาทีหลังบันทึก โดยสินค้าที่ไม่มีไฟล์ 3 มิติแล้วไม่แสดงทางเข้า "ดูแบบ 3 มิติ"

กรณีปกติ

- Given "เก้าอี้ผ้ากำมะหยี่" มีไฟล์ `chair.glb` เวลา 11:00
- When สมชายกด "เอาออก" แล้วกดบันทึก เวลา 11:01
- Then หน้าฟอร์มแสดงช่อง "ไฟล์ 3 มิติ" ว่าง และผู้ซื้อที่เปิดหน้าสินค้านี้เวลา 11:02 ไม่เห็นทางเข้า "ดูแบบ 3 มิติ" รูปสินค้ายังอยู่ครบ

กรณีผิดพลาด (ออกจากฟอร์มโดยไม่บันทึก)

- Given "เก้าอี้ผ้ากำมะหยี่" มีไฟล์ `chair.glb` เวลา 11:10
- When สมชายกด "เอาออก" แล้วออกจากหน้าฟอร์มโดยยืนยันทิ้งการแก้ไขตาม PRD-014
- Then สินค้ายังมีไฟล์ `chair.glb` เหมือนเดิม และหน้าสินค้ายังมีทางเข้า "ดูแบบ 3 มิติ"

### P3D-003 ทางเข้าในหน้าสินค้า

- ลำดับความสำคัญ: ต้องมี
- WHILE สินค้ามีไฟล์ 3 มิติ THE SYSTEM SHALL แสดงทางเข้า "ดูแบบ 3 มิติ" ต่อท้ายรูปสินค้าในแกลเลอรีของหน้าสินค้า และสินค้าที่ไม่มีไฟล์ 3 มิติแสดงแกลเลอรีเหมือนเดิมโดยไม่มีทางเข้านี้

กรณีปกติ

- Given "เก้าอี้ผ้ากำมะหยี่" มีรูป 3 รูปและมีไฟล์ 3 มิติ ส่วน "เสื้อยืดคอกลม" มีรูป 3 รูปและไม่มีไฟล์ 3 มิติ
- When สมหญิงเปิดหน้าสินค้าของทั้งสองชิ้น เวลา 12:00
- Then หน้าของ "เก้าอี้ผ้ากำมะหยี่" แสดงรูปย่อ 3 รูป ตามด้วยทางเข้า "ดูแบบ 3 มิติ" หน้าของ "เสื้อยืดคอกลม" แสดงรูปย่อ 3 รูปเท่านั้น และทั้งสองหน้าแสดงรูปปกเป็นรูปใหญ่ก่อน

กรณีผิดพลาด (สินค้าที่ผู้ซื้อเปิดไม่ได้)

- Given สมชายซ่อน "เก้าอี้ผ้ากำมะหยี่" เวลา 12:10
- When สมหญิงเปิดลิงก์หน้าสินค้านั้นเวลา 12:12
- Then เธอเห็นหน้าตาม BRW-007 ไม่เห็นรูปและไม่เห็นทางเข้า "ดูแบบ 3 มิติ"

### P3D-004 ดูแบบ 3 มิติ

- ลำดับความสำคัญ: ต้องมี
- WHEN ผู้ซื้อกด "ดูแบบ 3 มิติ" THE SYSTEM SHALL แสดงสินค้าแบบ 3 มิติแทนรูปใหญ่ในแกลเลอรี ให้หมุนด้วยการลากและซูมได้ โดยแสดงรูปปกพร้อมสัญลักษณ์กำลังโหลดระหว่างรอ และกลับไปแสดงรูปเมื่อผู้ซื้อกดรูปย่อรูปใดรูปหนึ่ง

กรณีปกติ

- Given สมหญิงเปิดหน้าสินค้า "เก้าอี้ผ้ากำมะหยี่" บนแล็ปท็อป เวลา 12:20
- When เธอกด "ดูแบบ 3 มิติ" แล้วลากเมาส์ไปทางซ้าย
- Then ระหว่างรอ เธอเห็นรูปปกกับสัญลักษณ์กำลังโหลด จากนั้นเห็นเก้าอี้แบบ 3 มิติที่หมุนตามการลาก ใช้คีย์บอร์ดหมุนได้ด้วยปุ่มลูกศร และเมื่อกดรูปย่อรูปที่ 2 พื้นที่รูปใหญ่กลับไปแสดงรูปที่ 2

กรณีผิดพลาด (โหลดไฟล์ไม่สำเร็จ)

- Given สมหญิงเปิดหน้าสินค้าเดิม เวลา 12:30 แล้วอินเทอร์เน็ตหลุด
- When เธอกด "ดูแบบ 3 มิติ"
- Then เธอเห็นข้อความ "แสดงภาพ 3 มิติไม่ได้ ลองใหม่อีกครั้ง" พร้อมปุ่ม "ลองใหม่" ในพื้นที่รูปใหญ่ รูปย่อและกล่องซื้อยังใช้ได้ตามปกติ

### P3D-005 ดูในห้องของคุณ

- ลำดับความสำคัญ: ต้องมี
- WHILE ผู้ซื้อกำลังดูแบบ 3 มิติบนอุปกรณ์ที่วางของในห้องผ่านกล้องได้ THE SYSTEM SHALL แสดงปุ่ม "ดูในห้องของคุณ" ซึ่งเมื่อกดจะเปิดกล้องและวางสินค้าที่ขนาดจริงตามไฟล์ โดยผู้ซื้อย่อขยายขนาดไม่ได้ และอุปกรณ์ที่ทำไม่ได้จะไม่แสดงปุ่มนี้

กรณีปกติ

- Given สมหญิงเปิดหน้าสินค้า "เก้าอี้ผ้ากำมะหยี่" บนมือถือ Android ที่วางของในห้องผ่านกล้องได้ เวลา 13:00 ไฟล์ 3 มิติของเก้าอี้สูง 0.83 เมตร
- When เธอกด "ดูแบบ 3 มิติ" แล้วกด "ดูในห้องของคุณ" และส่องกล้องไปที่พื้นห้อง
- Then เธอเห็นเก้าอี้วางบนพื้นห้องผ่านกล้อง สูง 0.83 เมตรเทียบกับของจริงในห้อง ย้ายตำแหน่งและหมุนได้ แต่ย่อขยายไม่ได้ เมื่อปิดกล้องเธอกลับมาที่หน้าสินค้าเดิม

กรณีผิดพลาด (อุปกรณ์ทำไม่ได้)

- Given สมหญิงเปิดหน้าสินค้าเดิมบนแล็ปท็อป เวลา 13:10
- When เธอกด "ดูแบบ 3 มิติ"
- Then เธอหมุนดูสินค้าได้ตาม P3D-004 และไม่เห็นปุ่ม "ดูในห้องของคุณ"

### P3D-006 ข้อมูลตัวอย่าง

- ลำดับความสำคัญ: ต้องมี
- THE SYSTEM SHALL มีสินค้าที่มีไฟล์ 3 มิติอย่างน้อย 2 ชิ้นในข้อมูลตัวอย่าง โดยสินค้าตัวอย่างชิ้นอื่นไม่มีไฟล์ 3 มิติ

กรณีปกติ

- Given เจ้าของโปรเจคเริ่มแอปด้วยข้อมูลตัวอย่าง 50 ร้าน 1,000 สินค้า
- When เขาเปิดหน้าสินค้าตัวอย่างที่ README ระบุว่ามีไฟล์ 3 มิติ
- Then เขาเห็นทางเข้า "ดูแบบ 3 มิติ" และหมุนดูสินค้าได้โดยไม่ต้องส่งไฟล์เอง

กรณีผิดพลาด (สินค้าตัวอย่างที่ไม่มีไฟล์)

- Given ข้อมูลตัวอย่างชุดเดียวกัน
- When เขาเปิดหน้าสินค้าตัวอย่างชิ้นอื่น
- Then หน้าสินค้าแสดงรูปตามปกติ ไม่มีทางเข้า "ดูแบบ 3 มิติ" และไม่มีพื้นที่ว่างหรือข้อความผิดพลาดแทน

### P3D-Q01 หน้าสินค้าไม่ช้าลงเพราะไฟล์ 3 มิติ

- ลำดับความสำคัญ: ต้องมี
- THE SYSTEM SHALL แสดงหน้าสินค้าที่มีไฟล์ 3 มิติภายในเวลาตาม BRW-Q01 โดยไม่โหลดไฟล์ 3 มิติจนกว่าผู้ซื้อจะกด "ดูแบบ 3 มิติ"

กรณีปกติ

- Given "เก้าอี้ผ้ากำมะหยี่" มีไฟล์ 3 มิติขนาด 3.9 MB
- When เปิดหน้าสินค้านี้ 100 ครั้งโดยไม่กดอะไร
- Then หน้าแสดงผลภายใน 2 วินาทีใน 95 จาก 100 ครั้ง และไม่มีคำขอไฟล์ 3 มิติเกิดขึ้นเลย

กรณีผิดพลาด

- Given ไฟล์ 3 มิติของสินค้านี้โหลดไม่ได้
- When สมหญิงเปิดหน้าสินค้าโดยไม่กด "ดูแบบ 3 มิติ"
- Then หน้าสินค้าแสดงรูป ราคา และปุ่มใส่ตะกร้าตามปกติภายในเวลาเดิม

### P3D-Q02 เวลาจนเห็นภาพ 3 มิติ

- ลำดับความสำคัญ: ควรมี
- WHEN ผู้ซื้อกด "ดูแบบ 3 มิติ" บนเครื่องเดียวกับที่รันแอป THE SYSTEM SHALL แสดงสินค้าแบบ 3 มิติที่หมุนได้ภายใน 5 วินาที ใน 9 จาก 10 ครั้ง สำหรับไฟล์ขนาดไม่เกิน 5 MB

กรณีปกติ

- Given "เก้าอี้ผ้ากำมะหยี่" มีไฟล์ 3 มิติขนาด 3.9 MB
- When กด "ดูแบบ 3 มิติ" 10 ครั้ง โดยเปิดหน้าใหม่ทุกครั้ง แล้วจับเวลาจากตอนกดจนสินค้าหมุนได้
- Then อย่างน้อย 9 ครั้งใช้เวลาไม่เกิน 5 วินาที

กรณีผิดพลาด

- Given การโหลดใช้เวลาเกิน 30 วินาที
- When สมหญิงยังรออยู่
- Then เธอเห็นข้อความและปุ่ม "ลองใหม่" ตาม P3D-004 แทนสัญลักษณ์กำลังโหลด

## 5. ข้อมูลและสถานะ

| ข้อมูล | ใช้ทำอะไร | เก็บนานแค่ไหน |
|---|---|---|
| ไฟล์ 3 มิติของสินค้า (ชนิด GLB ไม่เกิน 10 MB สินค้าละไม่เกินหนึ่งไฟล์) | แสดงสินค้าแบบ 3 มิติ และวางในห้องผ่านกล้อง | จนกว่าผู้ขายจะเอาออกหรือเปลี่ยน สินค้าที่ `ลบแล้ว` ไม่แสดงไฟล์นี้ที่ไหนอีก |
| ชื่อไฟล์และขนาดไฟล์ | แสดงให้ผู้ขายเห็นในหน้าฟอร์มว่าใส่ไฟล์ไหนไว้ | เท่ากับไฟล์ |

ไฟล์ 3 มิติไม่มีสถานะของตัวเอง การมองเห็นขึ้นกับสถานะของสินค้าตาม PRD

## 8. สมมติฐาน คำถามค้าง และบันทึก

### สมมติฐาน

- เจ้าของโปรเจคอนุมัติให้ศึกษาแล้วทำฟีเจอร์นี้เลย (2026-11-25)
- agent ตัดสินใจ: หนึ่งไฟล์ 3 มิติต่อสินค้า ไม่แยกตามแบบย่อย (2026-11-25)
- agent ตัดสินใจ: รับเฉพาะ GLB ไม่เกิน 10 MB ตามขนาดที่ผู้ให้บริการแอปกล้องของ Android แนะนำ (2026-11-25)
- agent ตัดสินใจ: วางในห้องที่ขนาดจริงและย่อขยายไม่ได้ เพื่อให้ผู้ซื้อเห็นว่าของพอดีกับห้องไหม (2026-11-25)
- agent ตัดสินใจ: ไฟล์ส่งไม่สำเร็จเมื่อเกิน 60 วินาที นานกว่ารูป (30 วินาที) เพราะไฟล์ใหญ่กว่ารูปสองเท่า (2026-11-25)
- agent ตัดสินใจ: ข้อมูลตัวอย่างใช้ไฟล์จากชุดตัวอย่างของ Khronos ที่มีสัญญาอนุญาต CC0 เท่านั้น (2026-11-25)
- agent ตัดสินใจ: 1 MB คือ 1,048,576 ไบต์ เหมือนขนาดรูปสินค้า ไฟล์ SheenChair (4,125,648 ไบต์) จึงแสดงเป็น "3.9 MB" (2026-11-25)
- agent ตัดสินใจ: ไฟล์ที่ไม่ผ่านเงื่อนไขถูกตรวจในเบราว์เซอร์ก่อนส่ง ข้อความขึ้นต้นด้วยชื่อไฟล์แบบเดียวกับรูป เช่น "photo.glb: ไฟล์ต้องเป็นชนิด GLB" และไม่แทนไฟล์เดิมในช่อง เซิร์ฟเวอร์ตรวจซ้ำอีกชั้น (2026-11-25)
- agent ตัดสินใจ: ปุ่มเลือกไฟล์ใช้คำ "เลือกไฟล์ 3 มิติ" และเปลี่ยนเป็น "เปลี่ยนไฟล์ 3 มิติ" เมื่อมีไฟล์แล้ว ชื่อไฟล์ยาวได้ไม่เกิน 255 ตัวอักษร (2026-11-25)
- agent ตัดสินใจ: ใช้ไฟล์ที่ร้านอื่นส่งขึ้นมาไม่ได้ (ตาม PRD-012) เห็นข้อความ "ไม่พบไฟล์ 3 มิติ เอาไฟล์นั้นออกแล้วใส่ใหม่" และไฟล์ที่ส่งขึ้นมาแต่ไม่มีสินค้าใช้เกิน 1 วัน ถูกลบตอนร้านนั้นส่งไฟล์ใหม่ แบบเดียวกับรูป (PRD-014) (2026-11-25)
- agent ตัดสินใจ: ทางเข้า "ดูแบบ 3 มิติ" เป็นปุ่มขนาดเท่ารูปย่อที่มีข้อความ สินค้าที่มีรูปเดียวแต่มีไฟล์ 3 มิติก็แสดงแถวรูปย่อ เพื่อให้มีทางเข้า (2026-11-25)
- agent ตัดสินใจ: ทางเข้า "ดูแบบ 3 มิติ" ยังอยู่ท้ายแถวรูปย่อและสูงเท่ารูปย่อ แต่เป็นเม็ดยาพื้นสีดอกดาวเรืองตัวหนา และเป็นพื้นเขียวอ่อนเมื่อเลือกอยู่ เพื่อให้เห็นเด่นกว่ารูปย่อ ตามทิศทางหน้าตารอบ 3 (2026-11-26)
- agent ตัดสินใจ: ข้อมูลตัวอย่างใช้ SheenChair กับ GlassVaseFlowers ผูกกับสินค้าชิ้นที่ 6 และ 12 ของร้าน "บ้านสวนช็อป" (`seller01`) ที่ตั้งชื่อใหม่เป็น "เก้าอี้ผ้ากำมะหยี่" และ "แจกันแก้วใส่ดอกไม้" (2026-11-25)
- agent ตัดสินใจ: P3D-Q02 จับเวลาจากกดจนตัวแสดงแจ้งว่าโหลดเสร็จ (event `load`) โดยเปิดเบราว์เซอร์ใหม่ที่ไม่มีแคชทุกครั้ง วัดใน `pnpm e2e` ทุกรอบพร้อม P3D-Q01 (2026-11-25)
