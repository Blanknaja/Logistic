## 1. เป้าหมายและตัวเลขความสำเร็จ

- เป้าหมาย: บัญชีที่เข้าสู่ระบบแล้วเปิดร้านของตัวเองได้ทันที ตั้งค่าร้านได้ มีหน้าแรกของหลังบ้านไว้เป็นทางเข้าไปจัดการร้าน และผู้ซื้อเปิดหน้าร้านดูสินค้าที่ร้านขายอยู่ได้
- วัดความสำเร็จจาก: คนที่ไม่เคยใช้ระบบเปิดร้านเสร็จภายใน 2 นาที นับจากกดเมนู "เปิดร้าน" จนเห็นหน้าแรกของหลังบ้าน โดยไม่มีใครช่วย ทดลอง 5 ครั้งต้องผ่านทั้ง 5 ครั้ง

## 2. ขอบเขต

### ทำ

- ทางเข้า "เปิดร้าน" และ "ร้านของฉัน" สำหรับบัญชีที่เข้าสู่ระบบแล้ว
- เปิดร้าน หนึ่งบัญชีหนึ่งร้าน เปิดได้ทันทีไม่ต้องรออนุมัติ
- ตั้งค่าร้าน: ชื่อร้าน คำอธิบายร้าน โลโก้ร้าน และที่อยู่ต้นทาง
- หน้าแรกของหลังบ้านของร้าน
- หน้าร้าน ที่แสดงสินค้าที่ร้านขายอยู่
- สิ่งที่ผู้ซื้อและผู้ขายเห็นเมื่อร้านถูกระงับ

### ไม่ทำ

- ไม่ทำการสร้างและแก้สินค้า เพราะอยู่ใน PRD
- ไม่ทำการจัดการสต็อก เพราะอยู่ใน INV
- ไม่ทำการจัดการคำสั่งซื้อฝั่งร้าน เพราะอยู่ใน ORD
- ไม่ทำรายงานยอดขาย เพราะอยู่ใน RPT
- ไม่ทำการกดระงับและเลิกระงับร้าน เพราะอยู่ใน ADM ไฟล์นี้กำหนดเฉพาะสิ่งที่เห็นหลังร้านถูกระงับแล้ว
- ไม่ทำการปิดร้านหรือลบร้าน เพราะเส้นทางหลักไม่ต้องใช้ และต้องตัดสินก่อนว่าสินค้ากับคำสั่งซื้อที่ค้างอยู่จะเป็นอย่างไร ร้านที่เปิดแล้วอยู่ตลอด
- ไม่ทำการโอนร้านไปให้บัญชีอื่น และไม่ทำหลายบัญชีดูแลร้านเดียวกัน เพราะรุ่นนี้หนึ่งร้านมีเจ้าของบัญชีเดียว
- ไม่ทำการค้นหา กรอง หรือเรียงสินค้าในหน้าร้าน เพราะการค้นหาอยู่ใน BRW
- ไม่ทำการติดตามร้าน คะแนนร้าน และการตกแต่งหน้าร้าน เพราะไม่ช่วยให้เดินเส้นทางหลักจบ
- ไม่ตรวจว่ารหัสไปรษณีย์ตรงกับจังหวัด เพราะไม่ได้ต่อกับบริษัทจัดส่งจริง

### ข้อจำกัด

- ต้องเสร็จพร้อม feature ชุด 1 เพื่อให้เดินเส้นทางหลักจบได้ในเช้าวันที่ 2026-11-25
- ใช้ผ่านเว็บ เปิดบนมือถือได้ ภาษาไทย ที่อยู่ต้นทางอยู่ในประเทศไทยเท่านั้น
- ต้องเข้าสู่ระบบก่อนจึงเปิดร้านและเข้าหลังบ้านของร้านได้ (ดู ACC)

## 3. ผู้ใช้และสิทธิ์

| บทบาท | ทำได้ | ทำไม่ได้ |
|---|---|---|
| คนที่ยังไม่เข้าสู่ระบบ | เปิดดูหน้าร้านของทุกร้าน | เปิดร้าน เข้าหลังบ้านของร้าน |
| ผู้ซื้อ (บัญชีที่ยังไม่มีร้าน) | เปิดดูหน้าร้านของทุกร้าน เปิดร้านของตัวเองได้ 1 ร้าน | เข้าหลังบ้านหรือแก้การตั้งค่าของร้านอื่น |
| ผู้ขาย | เข้าหน้าแรกของหลังบ้าน แก้ชื่อร้าน คำอธิบายร้าน โลโก้ร้าน และที่อยู่ต้นทางของร้านตัวเอง เปิดดูหน้าร้านของทุกร้าน | เปิดร้านที่สอง แก้ร้านของคนอื่น ปิดหรือลบร้าน แก้การตั้งค่าร้านขณะร้านถูกระงับ |
| ผู้ดูแลแพลตฟอร์ม | เปิดดูหน้าร้านของทุกร้าน ระงับร้าน (ดู ADM) | เปิดร้าน แก้การตั้งค่าร้านแทนผู้ขาย |

## 4. Requirements

### SHP-001 ทางเข้าเปิดร้านและร้านของฉัน

- ลำดับความสำคัญ: ต้องมี
- WHILE บัญชีเข้าสู่ระบบอยู่ THE SYSTEM SHALL แสดงเมนู "เปิดร้าน" ให้บัญชีที่ยังไม่มีร้าน และแสดงเมนู "ร้านของฉัน" ที่พาไปหน้าแรกของหลังบ้านให้บัญชีที่มีร้านแล้ว และพาบัญชีที่ยังไม่มีร้านไปหน้าเปิดร้านเมื่อบัญชีนั้นเปิดหน้าใดของหลังบ้านของร้าน

กรณีปกติ

- Given สมชายเข้าสู่ระบบแล้วและยังไม่มีร้าน เวลา 09:00
- When สมชายเปิดเมนูของบัญชี
- Then สมชายเห็นเมนู "เปิดร้าน" 1 รายการ และไม่เห็นเมนู "ร้านของฉัน" กดแล้วไปหน้าเปิดร้าน

กรณีปกติ (มีร้านแล้ว)

- Given สมชายมีร้าน "ร้านสมชายผ้าไทย" 1 ร้าน เวลา 09:10
- When สมชายเปิดเมนูของบัญชี
- Then สมชายเห็นเมนู "ร้านของฉัน" 1 รายการ และไม่เห็นเมนู "เปิดร้าน" กดแล้วไปหน้าแรกของหลังบ้าน

กรณีผิดพลาด

- Given สมหญิงยังไม่ได้เข้าสู่ระบบ เวลา 09:15
- When สมหญิงเปิดลิงก์หน้าเปิดร้านหรือหน้าหลังบ้านของร้านโดยตรง 1 ครั้ง
- Then สมหญิงถูกพาไปหน้าเข้าสู่ระบบ (ดู ACC-008) เข้าสู่ระบบสำเร็จแล้วกลับมาหน้าที่ตั้งใจเปิด และไม่มีร้านถูกสร้าง

กรณีผิดพลาด (ยังไม่มีร้าน)

- Given สมหญิงเข้าสู่ระบบแล้วและยังไม่มีร้าน เวลา 09:20
- When สมหญิงเปิดลิงก์หน้ารายการสินค้าของร้าน (PRD) หน้าสต็อก (INV) หรือหน้ารายการคำสั่งซื้อของร้าน (ORD) โดยตรง 1 ครั้ง
- Then สมหญิงถูกพาไปหน้าเปิดร้าน ไม่เห็นข้อมูลของร้านใด และไม่มีร้านถูกสร้าง

### SHP-002 เปิดร้าน

- ลำดับความสำคัญ: ต้องมี
- WHEN บัญชีที่ยังไม่มีร้านกรอกชื่อร้านและที่อยู่ต้นทางครบถ้วนแล้วกด "เปิดร้าน" THE SYSTEM SHALL สร้างร้านในสถานะ `เปิดอยู่` ทันทีโดยไม่ต้องรออนุมัติ แล้วพาไปหน้าแรกของหลังบ้าน

หน้าเปิดร้านเริ่มจากฟอร์มว่าง มีช่องบังคับ 8 ช่อง คือชื่อร้าน และที่อยู่ต้นทาง 7 ช่อง (ชื่อผู้ส่ง เบอร์โทร รายละเอียดที่อยู่ ตำบลหรือแขวง อำเภอหรือเขต จังหวัด รหัสไปรษณีย์) คำอธิบายร้านและโลโก้ร้านไม่บังคับ ใส่ตอนเปิดร้านหรือใส่ทีหลังก็ได้

กรณีปกติ

- Given สมชายเข้าสู่ระบบแล้ว ยังไม่มีร้าน และอยู่หน้าเปิดร้าน เวลา 10:00
- When สมชายกรอกชื่อร้าน "ร้านสมชายผ้าไทย" ชื่อผู้ส่ง "สมชาย ใจดี" เบอร์โทร 0812345678 ที่อยู่ "99/1 ถนนสุขุมวิท" แขวงคลองเตย เขตคลองเตย จังหวัดกรุงเทพมหานคร รหัสไปรษณีย์ 10110 แล้วกด "เปิดร้าน" เวลา 10:01
- Then สมชายเห็นหน้าแรกของหลังบ้านของ "ร้านสมชายผ้าไทย" ภายใน 2 วินาที พร้อมข้อความ "เปิดร้านสำเร็จ" ร้านมีสถานะ `เปิดอยู่` และเปิดหน้าร้านได้ทันที

กรณีผิดพลาด

- Given สมชายกรอกฟอร์มเปิดร้านครบ 8 ช่อง เวลา 10:01
- When สมชายกด "เปิดร้าน" แต่ระบบบันทึกไม่สำเร็จ หรือไม่ตอบภายใน 10 วินาที
- Then สมชายเห็นข้อความ "เปิดร้านไม่สำเร็จ ลองใหม่อีกครั้ง" ข้อมูลทั้ง 8 ช่องยังอยู่ในฟอร์ม ไม่มีร้านถูกสร้าง และกด "เปิดร้าน" ซ้ำได้

### SHP-003 ตรวจข้อมูลร้านก่อนบันทึก

- ลำดับความสำคัญ: ต้องมี
- IF ข้อมูลร้านที่ส่งมาตอนเปิดร้านหรือแก้การตั้งค่าร้านขาดช่องบังคับหรือผิดรูปแบบ THEN THE SYSTEM SHALL ไม่บันทึกข้อมูลใดเลย และแสดงข้อความบอกสาเหตุใต้ช่องที่ผิดทุกช่อง โดยคงข้อมูลที่กรอกไว้

กติกาของแต่ละช่อง

| ช่อง | กติกา |
|---|---|
| ชื่อร้าน | บังคับ 3 ถึง 30 ตัวอักษร ไม่นับช่องว่างหน้าและหลัง |
| คำอธิบายร้าน | ไม่บังคับ ไม่เกิน 500 ตัวอักษร |
| ชื่อผู้ส่ง | บังคับ 2 ถึง 50 ตัวอักษร |
| เบอร์โทร | บังคับ ตัวเลข 10 หลัก ขึ้นต้นด้วย 0 |
| รายละเอียดที่อยู่ | บังคับ 5 ถึง 200 ตัวอักษร |
| ตำบลหรือแขวง | บังคับ 1 ถึง 50 ตัวอักษร |
| อำเภอหรือเขต | บังคับ 1 ถึง 50 ตัวอักษร |
| จังหวัด | บังคับ เลือกจากรายชื่อ 77 จังหวัด |
| รหัสไปรษณีย์ | บังคับ ตัวเลข 5 หลัก |

กรณีปกติ

- Given สมชายอยู่หน้าเปิดร้าน เวลา 10:00
- When สมชายกรอกครบ 8 ช่องตามกติกา โดยเบอร์โทรเป็น 0812345678 และรหัสไปรษณีย์เป็น 10110 แล้วกด "เปิดร้าน"
- Then ไม่มีข้อความผิดพลาดใต้ช่องใด และร้านถูกสร้างตาม SHP-002

กรณีผิดพลาด

- Given สมชายอยู่หน้าเปิดร้าน เวลา 10:00
- When สมชายกรอกชื่อร้าน "สช" (2 ตัวอักษร) เบอร์โทร "08123" (5 หลัก) เว้นรหัสไปรษณีย์ว่าง ช่องอื่นกรอกถูก แล้วกด "เปิดร้าน"
- Then สมชายเห็นข้อความ 3 จุด คือ "ชื่อร้านต้องมี 3 ถึง 30 ตัวอักษร" "เบอร์โทรต้องเป็นตัวเลข 10 หลัก ขึ้นต้นด้วย 0" และ "กรุณากรอกรหัสไปรษณีย์ 5 หลัก" ข้อมูลช่องอื่นยังอยู่ครบ และไม่มีร้านถูกสร้าง

### SHP-004 ชื่อร้านไม่ซ้ำกัน

- ลำดับความสำคัญ: ต้องมี
- IF ชื่อร้านที่ส่งมาตรงกับชื่อของร้านอื่นที่มีอยู่แล้ว โดยไม่สนตัวพิมพ์เล็กใหญ่และช่องว่างหน้าหลัง THEN THE SYSTEM SHALL ไม่บันทึก และแสดงข้อความ "ชื่อร้านนี้มีคนใช้แล้ว" ใต้ช่องชื่อร้าน

กรณีปกติ

- Given มีร้านชื่อ "ร้านสมชายผ้าไทย" อยู่แล้ว 1 ร้าน และวิชัยอยู่หน้าเปิดร้าน เวลา 11:00
- When วิชัยกรอกชื่อร้าน "ร้านวิชัยผ้าไทย" และช่องอื่นถูกต้อง แล้วกด "เปิดร้าน"
- Then ร้าน "ร้านวิชัยผ้าไทย" ถูกสร้าง

กรณีผิดพลาด

- Given มีร้านชื่อ "ร้านสมชายผ้าไทย" อยู่แล้ว 1 ร้าน และวิชัยอยู่หน้าเปิดร้าน เวลา 11:00
- When วิชัยกรอกชื่อร้าน " ร้านสมชายผ้าไทย " (มีช่องว่างหน้าหลัง) แล้วกด "เปิดร้าน"
- Then วิชัยเห็นข้อความ "ชื่อร้านนี้มีคนใช้แล้ว" ข้อมูลช่องอื่นยังอยู่ และไม่มีร้านถูกสร้าง

กรณีผิดพลาด (สองคนทำพร้อมกัน)

- Given ยังไม่มีร้านชื่อ "บ้านกาแฟ" และวิชัยกับสมหญิงต่างอยู่หน้าเปิดร้าน เวลา 11:30
- When ทั้งสองคนกรอกชื่อร้าน "บ้านกาแฟ" แล้วกด "เปิดร้าน" ในวินาทีเดียวกัน
- Then คนที่ระบบรับก่อนได้ร้าน "บ้านกาแฟ" 1 ร้าน อีกคนเห็นข้อความ "ชื่อร้านนี้มีคนใช้แล้ว" และยังไม่มีร้าน

### SHP-005 หนึ่งบัญชีมีได้หนึ่งร้าน

- ลำดับความสำคัญ: ต้องมี
- IF บัญชีที่มีร้านอยู่แล้วหรือบัญชีผู้ดูแลแพลตฟอร์มพยายามเปิดร้าน THEN THE SYSTEM SHALL ไม่สร้างร้านเพิ่ม โดยพาบัญชีที่มีร้านแล้วไปหน้าแรกของหลังบ้านของร้านเดิม และแสดงข้อความ "บัญชีนี้เปิดร้านไม่ได้" แก่บัญชีผู้ดูแลแพลตฟอร์ม

กรณีปกติ

- Given สมชายมีร้าน "ร้านสมชายผ้าไทย" 1 ร้าน เวลา 12:00
- When สมชายเปิดลิงก์หน้าเปิดร้านโดยตรง
- Then สมชายถูกพาไปหน้าแรกของหลังบ้านของ "ร้านสมชายผ้าไทย" และยังมีร้าน 1 ร้านเท่าเดิม

กรณีผิดพลาด (กดซ้ำ)

- Given วิชัยยังไม่มีร้าน และกรอกฟอร์มเปิดร้านครบแล้ว เวลา 12:05
- When วิชัยกดปุ่ม "เปิดร้าน" 2 ครั้งติดกันภายใน 1 วินาที
- Then ปุ่มกดไม่ได้และขึ้นคำว่า "กำลังบันทึก" หลังกดครั้งแรก และวิชัยมีร้าน 1 ร้านเท่านั้น

กรณีผิดพลาด (เปิดสองหน้าจอ)

- Given วิชัยยังไม่มีร้าน และเปิดหน้าเปิดร้านทิ้งไว้ 2 หน้าจอ เวลา 12:10
- When วิชัยเปิดร้าน "ร้านวิชัยผ้าไทย" สำเร็จจากหน้าจอแรก แล้วกด "เปิดร้าน" จากหน้าจอที่สองด้วยชื่อ "ร้านวิชัย 2" เวลา 12:11
- Then หน้าจอที่สองพาไปหน้าแรกของหลังบ้านของ "ร้านวิชัยผ้าไทย" พร้อมข้อความ "คุณมีร้านอยู่แล้ว" และไม่มีร้าน "ร้านวิชัย 2"

### SHP-006 หน้าแรกของหลังบ้าน

- ลำดับความสำคัญ: ต้องมี
- WHEN ผู้ขายเปิดหน้าแรกของหลังบ้าน THE SYSTEM SHALL แสดงชื่อร้าน โลโก้ร้าน สถานะร้าน จำนวนสินค้าที่ขายอยู่ จำนวนคำสั่งซื้อที่รอร้านจัดของ (นับตาม ORD-004) และทางเข้าไปหน้ารายการสินค้าของร้าน (ดู PRD-001) หน้าสต็อก (ดู INV-001) หน้ารายการคำสั่งซื้อ (ดู ORD-001) หน้าตั้งค่าร้าน และหน้าร้านของตัวเอง

กรณีปกติ

- Given "ร้านสมชายผ้าไทย" ของสมชายมีสินค้าที่ขายอยู่ 3 ชิ้น และมีคำสั่งซื้อที่รอร้านจัดของ 2 รายการ เวลา 13:00
- When สมชายกดเมนู "ร้านของฉัน"
- Then สมชายเห็นชื่อ "ร้านสมชายผ้าไทย" สถานะ `เปิดอยู่` ตัวเลข "สินค้าที่ขายอยู่ 3" และ "คำสั่งซื้อที่รอร้านจัดของ 2" และทางเข้า 5 ทาง

กรณีปกติ (หน้าว่าง ร้านเพิ่งเปิด)

- Given วิชัยเพิ่งเปิดร้าน "ร้านวิชัยผ้าไทย" เวลา 13:05 ยังไม่มีสินค้าและคำสั่งซื้อ
- When วิชัยเห็นหน้าแรกของหลังบ้านเป็นครั้งแรก
- Then ตัวเลขทั้ง 2 ตัวเป็น 0 และมีข้อความ "ร้านของคุณยังไม่มีสินค้า" พร้อมปุ่ม "ลงสินค้าชิ้นแรก" ที่พาไปหน้าลงสินค้า (ดู PRD-002)

กรณีผิดพลาด

- Given สมชายเปิดหน้าแรกของหลังบ้าน เวลา 13:10
- When ระบบนับจำนวนคำสั่งซื้อที่รอร้านจัดของไม่สำเร็จ แต่ข้อมูลอื่นมาครบ
- Then ตัวเลขคำสั่งซื้อแสดงเป็น "-" พร้อมคำว่า "โหลดไม่สำเร็จ" และปุ่ม "ลองใหม่" ส่วนชื่อร้าน สถานะร้าน จำนวนสินค้า และทางเข้า 5 ทางยังแสดงและใช้ได้

### SHP-007 แก้ชื่อร้านและคำอธิบายร้าน

- ลำดับความสำคัญ: ต้องมี
- WHEN ผู้ขายแก้ชื่อร้านหรือคำอธิบายร้านในหน้าตั้งค่าร้านแล้วกด "บันทึก" THE SYSTEM SHALL บันทึกค่าใหม่ แสดงข้อความ "บันทึกแล้ว" และแสดงค่าใหม่ทุกที่ที่เห็นชื่อร้านและคำอธิบายร้านเมื่อเปิดหน้านั้นครั้งถัดไป

แก้ชื่อร้านได้ไม่จำกัดจำนวนครั้ง ลิงก์ของหน้าร้านคงเดิมแม้เปลี่ยนชื่อร้าน ถ้าบันทึกจากสองหน้าจอ ค่าที่บันทึกทีหลังเป็นค่าที่ใช้

กรณีปกติ

- Given สมชายอยู่หน้าตั้งค่าร้านของ "ร้านสมชายผ้าไทย" คำอธิบายร้านยังว่าง เวลา 14:00
- When สมชายแก้ชื่อร้านเป็น "สมชายผ้าไทยแท้" พิมพ์คำอธิบาย "ผ้าไหมทอมือจากสุรินทร์" (23 ตัวอักษร) แล้วกด "บันทึก" เวลา 14:01
- Then สมชายเห็นข้อความ "บันทึกแล้ว" และสมหญิงที่เปิดหน้าร้านเดิมด้วยลิงก์เดิมเวลา 14:02 เห็นชื่อ "สมชายผ้าไทยแท้" พร้อมคำอธิบายใหม่

กรณีปกติ (สองหน้าจอ ข้อมูลมาช้า)

- Given สมชายเปิดหน้าตั้งค่าร้านทิ้งไว้บนคอมพิวเตอร์และมือถือ รวม 2 หน้าจอ เวลา 14:10
- When สมชายบันทึกคำอธิบาย "ส่งทุกวัน" จากคอมพิวเตอร์เวลา 14:11 แล้วบันทึกคำอธิบาย "ส่งทุกวันจันทร์ถึงศุกร์" จากมือถือเวลา 14:12
- Then คำอธิบายร้านเป็น "ส่งทุกวันจันทร์ถึงศุกร์" และคอมพิวเตอร์เห็นค่านี้เมื่อเปิดหน้าตั้งค่าร้านใหม่

กรณีผิดพลาด

- Given สมชายแก้คำอธิบายร้านเป็นข้อความ 40 ตัวอักษร เวลา 14:20
- When สมชายกด "บันทึก" แต่ระบบบันทึกไม่สำเร็จ หรือไม่ตอบภายใน 10 วินาที
- Then สมชายเห็นข้อความ "บันทึกไม่สำเร็จ ลองใหม่อีกครั้ง" ข้อความ 40 ตัวอักษรยังอยู่ในช่อง และหน้าร้านยังแสดงคำอธิบายเดิม

### SHP-008 โลโก้ร้าน

- ลำดับความสำคัญ: ต้องมี
- WHEN ผู้ขายเลือกรูปเป็นโลโก้ร้านแล้วกด "บันทึก" THE SYSTEM SHALL ใช้รูปนั้นเป็นโลโก้ร้านแทนรูปเดิม เมื่อรูปเป็นไฟล์ JPG หรือ PNG ขนาดไม่เกิน 2 MB และปฏิเสธรูปที่ไม่ตรงเงื่อนไขโดยคงโลโก้เดิมไว้

ร้านที่ยังไม่มีโลโก้ แสดงตัวอักษรตัวแรกของชื่อร้านในวงกลมแทน ผู้ขายกด "ลบโลโก้" เพื่อกลับไปใช้ตัวอักษรได้

กรณีปกติ

- Given "ร้านสมชายผ้าไทย" ยังไม่มีโลโก้ ทุกที่แสดงตัวอักษร "ร" เวลา 15:00
- When สมชายเลือกรูป PNG ขนาด 1.2 MB เห็นรูปตัวอย่างในหน้าตั้งค่าร้าน แล้วกด "บันทึก" เวลา 15:01
- Then สมชายเห็นข้อความ "บันทึกแล้ว" และหน้าร้านกับหน้าแรกของหลังบ้านแสดงรูปใหม่แทนตัวอักษร "ร"

กรณีผิดพลาด

- Given "ร้านสมชายผ้าไทย" มีโลโก้อยู่แล้ว 1 รูป เวลา 15:10
- When สมชายเลือกรูป JPG ขนาด 5 MB หรือไฟล์ PDF 1 ไฟล์
- Then สมชายเห็นข้อความ "ใช้ได้เฉพาะรูป JPG หรือ PNG ขนาดไม่เกิน 2 MB" และโลโก้เดิมยังแสดงอยู่

กรณีผิดพลาด (ส่งรูปไม่จบ)

- Given สมชายเลือกรูป PNG ขนาด 1.8 MB แล้วกด "บันทึก" เวลา 15:20
- When การเชื่อมต่อหลุดระหว่างส่งรูป
- Then สมชายเห็นข้อความ "อัปโหลดรูปไม่สำเร็จ ลองใหม่อีกครั้ง" และโลโก้เดิมยังแสดงอยู่ทุกที่

### SHP-009 แก้ที่อยู่ต้นทาง

- ลำดับความสำคัญ: ต้องมี
- WHEN ผู้ขายแก้ที่อยู่ต้นทางในหน้าตั้งค่าร้านแล้วกด "บันทึก" THE SYSTEM SHALL บันทึกที่อยู่ใหม่ และใช้ที่อยู่ใหม่กับพัสดุที่ถูกสร้างหลังเวลาบันทึกเท่านั้น

ร้านมีที่อยู่ต้นทางได้ 1 ที่อยู่ พัสดุที่ถูกสร้างไปแล้วใช้ที่อยู่ต้นทาง ณ เวลาที่พัสดุถูกสร้าง (ดู DLV-001)

กรณีปกติ

- Given ที่อยู่ต้นทางของ "ร้านสมชายผ้าไทย" คือเขตคลองเตย กรุงเทพมหานคร 10110 และร้านมีพัสดุ 1 ชิ้นที่ถูกสร้างเวลา 15:30
- When สมชายแก้ที่อยู่ต้นทางเป็น "12 ถนนนิมมานเหมินท์" ตำบลสุเทพ อำเภอเมืองเชียงใหม่ จังหวัดเชียงใหม่ 50200 แล้วกด "บันทึก" เวลา 16:00
- Then สมชายเห็นข้อความ "บันทึกแล้ว" พัสดุที่ถูกสร้างเวลา 15:30 ยังใช้ที่อยู่คลองเตย พัสดุที่ถูกสร้างเวลา 16:05 ใช้ที่อยู่เชียงใหม่ และหน้าร้านแสดงจังหวัดเป็น "เชียงใหม่"

กรณีผิดพลาด

- Given สมชายอยู่หน้าตั้งค่าร้าน เวลา 16:10
- When สมชายลบเบอร์โทรจนว่าง แล้วกด "บันทึก"
- Then สมชายเห็นข้อความ "เบอร์โทรต้องเป็นตัวเลข 10 หลัก ขึ้นต้นด้วย 0" ตาม SHP-003 และที่อยู่ต้นทางเดิมทั้ง 7 ช่องยังเป็นค่าที่ใช้อยู่

### SHP-010 ออกจากฟอร์มกลางทาง

- ลำดับความสำคัญ: ต้องมี
- IF ผู้ใช้ออกจากหน้าเปิดร้านหรือหน้าตั้งค่าร้านขณะมีข้อมูลที่แก้แล้วยังไม่บันทึก THEN THE SYSTEM SHALL ถามยืนยันก่อนออก และไม่บันทึกข้อมูลที่ค้างอยู่เมื่อผู้ใช้ยืนยันออก

กรณีปกติ

- Given สมชายแก้คำอธิบายร้านในหน้าตั้งค่าร้านไป 1 ช่อง ยังไม่กด "บันทึก" เวลา 16:30
- When สมชายกด "ยกเลิก" แล้วเลือก "อยู่ต่อ" ในคำถาม "ยังไม่ได้บันทึก ต้องการออกจากหน้านี้ไหม"
- Then สมชายยังอยู่หน้าตั้งค่าร้าน และข้อความที่แก้ไว้ยังอยู่ในช่อง

กรณีผิดพลาด

- Given วิชัยยังไม่มีร้าน กรอกฟอร์มเปิดร้านไปแล้ว 4 จาก 8 ช่อง เวลา 16:40
- When วิชัยกดกลับไปหน้าแรกของเว็บ แล้วเลือก "ออก" ในคำถามยืนยัน
- Then ไม่มีร้านถูกสร้าง วิชัยยังเห็นเมนู "เปิดร้าน" และเมื่อเปิดหน้าเปิดร้านอีกครั้งเวลา 16:45 ฟอร์มว่างทั้ง 8 ช่อง

### SHP-011 หน้าร้าน

- ลำดับความสำคัญ: ต้องมี
- WHEN ใครก็ตามเปิดหน้าร้านของร้านที่มีสถานะ `เปิดอยู่` ไม่ว่าเข้าสู่ระบบแล้วหรือยัง THE SYSTEM SHALL แสดงโลโก้ร้าน ชื่อร้าน คำอธิบายร้าน จังหวัดของที่อยู่ต้นทาง วันที่เปิดร้าน จำนวนสินค้าที่ขายอยู่ และรายการสินค้าที่ขายอยู่ของร้านนั้นเรียงจากที่ลงล่าสุดก่อน ครั้งละ 20 ชิ้น

- สินค้าที่ขายอยู่คือสินค้าของร้านที่มีสถานะ `ขายอยู่` (ดู PRD ส่วนที่ 5) แต่ละชิ้นแสดงรูปปก ชื่อ และราคาแบบเดียวกับรายการสินค้าใน BRW-001 กดแล้วไปหน้ารายละเอียดสินค้า (ดู BRW-008)
- สินค้าที่ขายอยู่แต่สต็อกของทุกแบบย่อยเป็น 0 ยังแสดงอยู่ พร้อมป้าย "สินค้าหมด" (ดู INV)
- ถ้ามีมากกว่า 20 ชิ้น มีปุ่ม "ดูเพิ่ม" ที่แสดงเพิ่มอีกครั้งละ 20 ชิ้น
- หน้าร้านไม่แสดงชื่อผู้ส่ง เบอร์โทร และที่อยู่ต้นทางส่วนอื่นนอกจากจังหวัด
- ร้านที่ไม่มีคำอธิบายแสดง "ร้านนี้ยังไม่มีคำอธิบาย"
- เจ้าของร้านเห็นปุ่ม "แก้ไขร้าน" ที่พาไปหน้าตั้งค่าร้าน คนอื่นไม่เห็นปุ่มนี้

กรณีปกติ

- Given "ร้านสมชายผ้าไทย" เปิดเมื่อ 2026-11-24 ที่อยู่ต้นทางอยู่กรุงเทพมหานคร มีสินค้าที่ขายอยู่ 23 ชิ้น โดย 1 ชิ้นมีสต็อก 0
- When สมหญิงซึ่งยังไม่ได้เข้าสู่ระบบเปิดหน้าร้านนี้ เวลา 17:00
- Then สมหญิงเห็นชื่อร้าน "กรุงเทพมหานคร" "เปิดร้านเมื่อ 24/11/2026" "สินค้า 23 ชิ้น" สินค้า 20 ชิ้นแรกเรียงจากที่ลงล่าสุด ชิ้นที่สต็อก 0 มีป้าย "สินค้าหมด" และเมื่อกด "ดูเพิ่ม" เห็นอีก 3 ชิ้น แล้วปุ่ม "ดูเพิ่ม" หายไป

กรณีผิดพลาด

- Given สมหญิงเห็นสินค้า 20 ชิ้นแรกของ "ร้านสมชายผ้าไทย" แล้ว เวลา 17:05
- When สมหญิงกด "ดูเพิ่ม" แต่ระบบโหลดสินค้าชุดถัดไปไม่สำเร็จ
- Then สินค้า 20 ชิ้นแรกยังแสดงอยู่ และใต้รายการมีข้อความ "โหลดสินค้าเพิ่มไม่สำเร็จ" พร้อมปุ่ม "ลองใหม่"

### SHP-012 หน้าร้านที่ไม่มีสินค้า และร้านที่ไม่มีอยู่

- ลำดับความสำคัญ: ต้องมี
- IF หน้าร้านที่ถูกเปิดไม่มีสินค้าที่ขายอยู่ หรือลิงก์ไม่ตรงกับร้านใดเลย THEN THE SYSTEM SHALL แสดงข้อความ "ร้านนี้ยังไม่มีสินค้า" แทนรายการสินค้าในกรณีแรก และแสดงหน้า "ไม่พบร้านนี้" พร้อมปุ่มกลับหน้าแรกของเว็บในกรณีหลัง

กรณีปกติ

- Given วิชัยเปิดร้าน "ร้านวิชัยผ้าไทย" เวลา 13:05 และยังไม่มีสินค้าที่ขายอยู่ (0 ชิ้น)
- When สมหญิงเปิดหน้าร้านนี้ เวลา 17:30
- Then สมหญิงเห็นโลโก้ร้าน ชื่อร้าน และ "สินค้า 0 ชิ้น" ตามปกติ และเห็นข้อความ "ร้านนี้ยังไม่มีสินค้า" แทนรายการสินค้า เมื่อวิชัยเปิดหน้าเดียวกัน วิชัยเห็นปุ่ม "ลงสินค้าชิ้นแรก" เพิ่มอีก 1 ปุ่ม

กรณีผิดพลาด

- Given ไม่มีร้านใดตรงกับลิงก์ที่สมหญิงได้รับมา 1 ลิงก์ เวลา 17:35
- When สมหญิงเปิดลิงก์นั้น
- Then สมหญิงเห็นหน้า "ไม่พบร้านนี้" พร้อมปุ่ม "กลับหน้าแรก" และไม่เห็นข้อมูลของร้านใด

### SHP-013 สถานะกำลังโหลดและโหลดไม่สำเร็จ

- ลำดับความสำคัญ: ต้องมี
- WHILE ข้อมูลของหน้าเปิดร้าน หน้าแรกของหลังบ้าน หน้าตั้งค่าร้าน หรือหน้าร้านยังมาไม่ถึง THE SYSTEM SHALL แสดงโครงหน้าพร้อมตัวบอกว่ากำลังโหลดแทนเนื้อหา และเปลี่ยนเป็นข้อความ "โหลดข้อมูลไม่สำเร็จ" พร้อมปุ่ม "ลองใหม่" เมื่อโหลดล้มเหลวหรือครบ 10 วินาที

ระหว่างกำลังโหลด ปุ่ม "เปิดร้าน" และ "บันทึก" กดไม่ได้ หน้าตั้งค่าร้านไม่แสดงฟอร์มว่างแทนข้อมูลที่ยังมาไม่ถึง

กรณีปกติ

- Given สมชายมีร้าน "ร้านสมชายผ้าไทย" และการเชื่อมต่อช้า เวลา 18:00
- When สมชายเปิดหน้าตั้งค่าร้าน และข้อมูลมาถึงหลังผ่านไป 3 วินาที
- Then ช่วง 3 วินาทีแรกสมชายเห็นโครงหน้าพร้อมตัวบอกว่ากำลังโหลด ปุ่ม "บันทึก" กดไม่ได้ จากนั้นเห็นข้อมูลร้านครบและปุ่ม "บันทึก" กดได้

กรณีผิดพลาด

- Given สมหญิงเปิดหน้าร้านของ "ร้านสมชายผ้าไทย" เวลา 18:05
- When ข้อมูลยังไม่มาถึงเมื่อครบ 10 วินาที
- Then สมหญิงเห็นข้อความ "โหลดข้อมูลไม่สำเร็จ" พร้อมปุ่ม "ลองใหม่" กด 1 ครั้งแล้วหน้าเริ่มโหลดใหม่ และเมื่อข้อมูลมาถึงก็แสดงหน้าร้านตามปกติ

### SHP-014 ร้านที่ถูกระงับ

- ลำดับความสำคัญ: ต้องมี
- WHILE ร้านมีสถานะ `ถูกระงับ` THE SYSTEM SHALL แสดงหน้าร้านเป็นชื่อร้าน โลโก้ร้าน และข้อความ "ร้านนี้ถูกระงับ ซื้อสินค้าจากร้านนี้ไม่ได้ในขณะนี้" โดยไม่มีรายการสินค้า แสดงแถบ "ร้านของคุณถูกระงับโดยผู้ดูแลแพลตฟอร์ม" บนทุกหน้าของหลังบ้านของร้าน และไม่รับการแก้การตั้งค่าร้าน

- การระงับและเลิกระงับทำโดยผู้ดูแลแพลตฟอร์ม (ดู ADM)
- ขณะถูกระงับ ผู้ขายยังเข้าหลังบ้านของร้าน ดูการตั้งค่าร้าน และจัดการคำสั่งซื้อที่มีอยู่ก่อนถูกระงับได้ (ดู ORD)
- ขณะถูกระงับ สินค้าของร้านไม่แสดงในผลการค้นหาและซื้อไม่ได้ (ดู BRW-007 CRT-014 CHK-006)
- เมื่อเลิกระงับ หน้าร้านและการตั้งค่าร้านกลับมาเหมือนก่อนถูกระงับ ข้อมูลร้านไม่หาย

กรณีปกติ

- Given "ร้านสมชายผ้าไทย" มีสินค้าที่ขายอยู่ 23 ชิ้น และถูกระงับเวลา 19:00
- When สมหญิงเปิดหน้าร้านนี้เวลา 19:05 และสมชายเปิดหน้าแรกของหลังบ้านเวลา 19:06
- Then สมหญิงเห็นชื่อร้าน โลโก้ร้าน และข้อความ "ร้านนี้ถูกระงับ ซื้อสินค้าจากร้านนี้ไม่ได้ในขณะนี้" เห็นสินค้า 0 ชิ้น ส่วนสมชายเห็นแถบ "ร้านของคุณถูกระงับโดยผู้ดูแลแพลตฟอร์ม" สถานะร้าน `ถูกระงับ` และยังเข้าหน้าคำสั่งซื้อได้

กรณีผิดพลาด

- Given สมชายเปิดหน้าตั้งค่าร้านทิ้งไว้ตั้งแต่เวลา 18:55 และร้านถูกระงับเวลา 19:00
- When สมชายแก้ชื่อร้านเป็น "สมชายผ้าไทยใหม่" แล้วกด "บันทึก" เวลา 19:02
- Then สมชายเห็นข้อความ "ร้านถูกระงับ แก้การตั้งค่าร้านไม่ได้" ชื่อร้านยังเป็นชื่อเดิม และเมื่อเปิดหน้าตั้งค่าร้านใหม่ ทุกช่องอ่านได้อย่างเดียว

### SHP-015 เฉพาะเจ้าของร้านเข้าหลังบ้านและแก้ร้านได้

- ลำดับความสำคัญ: ต้องมี
- IF บัญชีที่ไม่ใช่เจ้าของร้านพยายามเปิดหลังบ้านหรือแก้การตั้งค่าของร้านนั้น THEN THE SYSTEM SHALL ปฏิเสธ แสดงข้อความ "ไม่พบหน้านี้" และไม่เปิดเผยหรือเปลี่ยนข้อมูลของร้านนั้น

กรณีปกติ

- Given สมชายเป็นเจ้าของ "ร้านสมชายผ้าไทย" และเข้าสู่ระบบอยู่ เวลา 20:00
- When สมชายเปิดหน้าตั้งค่าร้านของตัวเอง
- Then สมชายเห็นชื่อร้าน คำอธิบายร้าน โลโก้ร้าน และที่อยู่ต้นทางครบ 7 ช่อง และแก้ได้

กรณีผิดพลาด

- Given วิชัยเป็นเจ้าของ "ร้านวิชัยผ้าไทย" และเข้าสู่ระบบอยู่ เวลา 20:05
- When วิชัยพยายามเปิดหน้าตั้งค่าร้านของ "ร้านสมชายผ้าไทย" หรือส่งคำขอแก้ชื่อร้านนั้น 1 ครั้ง
- Then วิชัยเห็นข้อความ "ไม่พบหน้านี้" ไม่เห็นเบอร์โทรและที่อยู่ต้นทางของสมชาย และชื่อ "ร้านสมชายผ้าไทย" ไม่เปลี่ยน

กรณีผิดพลาด (หมดเวลาเข้าสู่ระบบ)

- Given สมชายเปิดหน้าตั้งค่าร้านทิ้งไว้ตั้งแต่เวลา 20:10 และการเข้าสู่ระบบหมดอายุไปแล้ว (ดู ACC-006)
- When สมชายแก้คำอธิบายร้าน 1 ช่อง แล้วกด "บันทึก" เวลา 23:00
- Then สมชายถูกพาไปหน้าเข้าสู่ระบบพร้อมข้อความ "กรุณาเข้าสู่ระบบอีกครั้ง" และคำอธิบายร้านยังเป็นค่าเดิม

## 5. ข้อมูลและสถานะ

คำที่ใช้ในไฟล์นี้

- หน้าร้าน: หน้าที่ทุกคนเปิดดูได้ แสดงข้อมูลร้านและสินค้าที่ร้านขายอยู่
- หลังบ้านของร้าน: กลุ่มหน้าที่เฉพาะเจ้าของร้านเข้าได้ ใช้จัดการร้านของตัวเอง
- ที่อยู่ต้นทาง: ที่อยู่ที่ร้านใช้ส่งพัสดุออก
- สินค้าที่ขายอยู่: สินค้าของร้านที่มีสถานะ `ขายอยู่` (ดู PRD ส่วนที่ 5)

| ข้อมูล | ใช้ทำอะไร | เก็บนานแค่ไหน |
|---|---|---|
| เจ้าของร้าน (บัญชี 1 บัญชี) | บอกว่าใครเข้าหลังบ้านและแก้ร้านได้ เปลี่ยนไม่ได้ | ตลอด |
| ชื่อร้าน | แสดงในหน้าร้านและทุกที่ที่อ้างถึงร้าน ไม่ซ้ำกับร้านอื่น | ตลอด เก็บเฉพาะค่าล่าสุด |
| คำอธิบายร้าน | แสดงในหน้าร้าน | ตลอด เก็บเฉพาะค่าล่าสุด |
| โลโก้ร้าน | แสดงในหน้าร้านและหลังบ้านของร้าน | ตลอด เก็บเฉพาะรูปล่าสุด รูปเก่าเลิกแสดงทันทีที่เปลี่ยน |
| ที่อยู่ต้นทาง (ชื่อผู้ส่ง เบอร์โทร รายละเอียดที่อยู่ ตำบลหรือแขวง อำเภอหรือเขต จังหวัด รหัสไปรษณีย์) | เป็นจุดเริ่มของพัสดุ (ดู DLV-001) หน้าร้านแสดงเฉพาะจังหวัด | ตลอด เก็บเฉพาะค่าล่าสุด |
| วันและเวลาที่เปิดร้าน | แสดงในหน้าร้าน | ตลอด |
| สถานะร้าน | กำหนดสิ่งที่ผู้ซื้อและผู้ขายเห็น | ตลอด |

| จากสถานะ | เหตุการณ์ | ไปสถานะ |
|---|---|---|
| ยังไม่มีร้าน | บัญชีกด "เปิดร้าน" และข้อมูลผ่านการตรวจ | `เปิดอยู่` |
| `เปิดอยู่` | ผู้ดูแลแพลตฟอร์มระงับร้าน (ดู ADM) | `ถูกระงับ` |
| `ถูกระงับ` | ผู้ดูแลแพลตฟอร์มเลิกระงับร้าน (ดู ADM) | `เปิดอยู่` |

ไม่มีสถานะปิดร้านหรือลบร้านในรอบนี้

### สมมติฐาน
